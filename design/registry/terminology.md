# Canonical Terminology

Use the preferred term in all player-facing copy. Internal identifiers may migrate separately but must not leak.

| Preferred        | Meaning                                           | Avoid                            |
| ---------------- | ------------------------------------------------- | -------------------------------- |
| Anotherverse     | Game and mythic setting frame                     | breach network                   |
| hero             | A playable character                              | operator, unit                   |
| company / party  | The recruited group                               | squad, response team             |
| Mythic Awakening | A hero’s personal evolving power                  | Mythic Path, licence             |
| class            | Oathward, Doomseeker, or Fateweaver rules chassis | role label during hero selection |
| skill            | A learned executable ability                      | feature payload                  |
| technique        | An Awakening-linked executable ability            | technique in action              |
| formation        | Front, middle, and rear placement                 | deployment geometry              |
| stance           | Guarded, Aggressive, Tactical, Supportive         | posture protocol                 |
| target priority  | Autobattle targeting rule                         | command doctrine                 |
| Rations          | Recovery/travel consumable                        | provisions in UI                 |
| Coin             | Purchase currency                                 | credits                          |
| Relic Dust       | Fusion/upgrade catalyst                           | data, fragments                  |
| monster material | Creature-derived fusion input                     | component payload                |
| Danger           | Encounter escalation meter, only if mechanical    | threat telemetry                 |
| Readiness        | Technique capacity, only if mechanical            | operational readiness            |
| Renown           | Company reputation, only if it unlocks content    | licence score                    |

## Voice

Write vivid mythology in plain English. Name the subject, action, and consequence. Rules text uses: **effect; trigger; cost**. Do not stack synonyms, ornamental abstractions, or unexplained proper nouns.

Example: “The lion spirit shields the front row. When an ally there is struck, gain 3 Guard. Costs 1 power.”
